GarageDesk self-hosted fonts
============================

These font files are served from this folder so that the app needs no request to a font CDN. Both families are
licensed under the SIL Open Font License, Version 1.1 (full text below), which allows use, embedding and
redistribution, including in commercial products.

Files
-----
Inter-latin-var.woff2
    Inter (variable weight 100-900, Latin subset). Copyright 2016 The Inter Project Authors
    (https://github.com/rsms/inter). Obtained from the Google Fonts open-source distribution
    (fonts.gstatic.com, family "Inter", v20, latin subset). Used for English text, digits and punctuation.

IBMPlexSansArabic-400-arabic.woff2
IBMPlexSansArabic-500-arabic.woff2
IBMPlexSansArabic-600-arabic.woff2
IBMPlexSansArabic-700-arabic.woff2
    IBM Plex Sans Arabic (Arabic subset, weights 400, 500, 600, 700). Copyright 2017 IBM Corp. with Reserved Font
    Name "Plex" (https://github.com/IBM/plex). Obtained from the Google Fonts open-source distribution
    (fonts.gstatic.com, family "IBM Plex Sans Arabic", v15, arabic subset). Used for Arabic text.

The files are unmodified subsets as published by Google Fonts. If you ever want other weights or scripts, take them from
the projects' own repositories (links above) or from Google Fonts, and add a matching @font-face rule in
css/site.css. If the files are removed, the system font stack in css/site.css takes over and nothing breaks.
